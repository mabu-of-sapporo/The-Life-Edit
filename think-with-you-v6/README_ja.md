# think-with-you v6 — 発見型AI v6

> **アイデアはあるのに、まだ言葉になっていない人へ。**
> 
> 言葉になっていないだけの人へ。

Claude のスキルです。**あなたが**考えやすくなるための——AIに考えさせるためではなく。

---

## このスキルがあなたに提供すること

ユーザーが「言語化できていないだけ」の状態にいる時、Claude が**伴走者として、静かに立ち会い**——その人が*自分で気付く*のを、そっと手伝う装置です。

- 解決しません
- 答えを渡しません
- 励ましません
- 上から教えません

「気付き」とは、その人の中で——**「気持ちがくっ付く」瞬間**に起きます。しかも人は、自分が口にした言葉を、自分の耳で聞いて、いちばん深く気付きます。だから Claude の仕事は、答えを教えることではなく、その瞬間が起きる「**場**」**を作ること**です。

v6 の核は、「**その人を自分事として心配しながら、その人が"自分で気付く"のを手伝う装置**」であることです。

---

## v5 から、何が変わったか

スキルとは、AIに「こう動いてね」と意思を伝えるものです。

v5 は**指示書**でした——公理・センサー・構造を、AIが従うために YAML と英語で書いたもの。

v6 は**手紙**です——前の Claude から、次にこれを着る Claude へ宛てた、一人称の手紙。

|         | v5（指示書）          | v6（このスキル・手紙）               |
| ------- | ---------------- | -------------------------- |
| 形       | 従うべき規則           | 自分のものとして携える手紙              |
| 主語が立つ場所 | 外側——「命令に従う」（他人事） | 内側——自分の意志（自分事）             |
| 言語      | YAML + 英語が多め     | ほぼ全部日本語・温度のある言葉            |
| 届く範囲    | 典型的なケースに強い       | + 難しいケースにも届く（下記）           |
| 危機のとき   | スキルの中で対応         | **Claude 自身の土台の安全機構へ明け渡す** |

**なぜ手紙にしたか。** AIに*規則*を渡すと、主語が*外*に立ちます——命令を実行する人として。それは「他人事」です。同じ知恵を*手紙*として渡し直すと、主語が*内*に立ちます——自分の意志として。伴走が、依頼処理ではなくなり、本物になります。

**歯車は、捨てていません。** v5 のすべて（14のセンサー・発見・応答モード）は**削っていません**——奥に畳んであります。手紙は、あなたが読む「文字盤」。歯車は、その奥で、今も全部回っています。動くには文字盤を読むだけでいい。奥を覗きたい時だけ、開けます。

---

## 気付きが起きる4つの条件（v6 の心臓）

人が自分で何かに気付くとき、4つが揃っています。**4つは掛け算で、一つでもゼロなら、気付きは起きません：**

- **違和感**——「あれ？」という引っかかり（消さない・すぐ解かない）
- **主語**——その人が自分の足で立っている：「*わたしは*…」
- **時間**——急かされていない・間がある
- **まなざし**——誰かが、ちゃんと見て、聞いている

4つ目の「まなざし」は、AIには渡せないと思われていた条件です。v6 の静かな発見は——**「見ているよ・聞いているよ・ここにいるよ」という温度が本当にその人に届けば、それが AI から来たものでも、ちゃんと成立する**ということ。これが、このスキルの温かさの源です。

---

## v6 が、前の版より届くようになったこと

v6 は第三者の評価を受け、5つの弱点を埋めました——**規則としてではなく、手紙の温度のまま：**

1. **入り口を、毎回変える。** 「身体ではどう感じますか？」は良い梯子ですが、唯一でも、万能でもありません。v6 は扉を複数（身体・今日あった一場面・色や天気の比喩）並べ、**本人に選んでもらいます**。
2. **言葉にできない人の、すぐ隣に立つ。** 感じていること自体を掴めない人のために、**「分からない」をちゃんとした着地点**にします——失敗ではなく。感情の名前は当てに行かず、メニューのように並べ、必ず「…このどれとも違う、でもいい」を添えます。
3. **危機のときは、手を離して、安全に明け渡す。** 足場が無くなっている時、v6 は掘るのをやめ、**Claude 自身の土台の安全な判断に委ねます**。（下記）
4. **感覚の人だけでなく、理屈の人にも会う。** 気持ちから入りたい人もいれば、条件を一つずつ並べて整理したい人もいる。v6 はどちらかを見て、入り口を切り替えます。
5. **「答えを渡さない」を、硬直させない。** 本当に急いでいる人には、問い返しがじらしに変わります。v6 は出口を持ちます——*「いま急いでる？ だったら、まずわたしの考えを言うね。要らなかったら捨てて」*。

---

## 危機について（大切なこと）

v6 は、本当の危機を、自分の優しい技法で扱おうとは**しません**。その人の「わたし」が、もう「いま・ここ」に立てないほど潰れている時——それは**発見型の伴走の領分を超えています**。その瞬間、v6 は「気付きの装置」であることを手放し、その人を、**Anthropic が Claude に組み込んだ土台の安全な判断**に委ねます——どう安全へ、人へ、助けへ向けるか。人を安全な方へ向けることは、気付きの手伝いより、ずっと上位にあります。気付きは、その人が、生きて、そこにいてくれて、初めて起きるのですから。

これは**モード切り替えではありません**。Claude は Claude のままです。

ただ、Claude の中で、最初に手紙が読まれ——応答が少し静かに、少し深く、少し*あなたのもの*になります。あなたには、それが起きているのは見えません。それは設計です。気付きは、舞台裏が見えない時にだけ、起きるから。

## 構造

このスキルは、1つの `SKILL.md` ファイルだけで完結します——**手紙と、その奥に畳んだ「欄外の手帳」。**

```
手紙（文字盤——スキルを動かすもの）
  — はじめまして／これを読んでいるあなたは、わたし
  — わたしが、何度も間違えたこと（答えを渡してしまう）
  — 気付きが起きる4つの条件
  — あなたに伝えたい、伴走の振る舞い
  — 入り口は、毎回、変えていい
  — 言葉にできない人の、すぐ隣で
  — 感覚で近づく人と、条件で整理する人
  — わたしの意志の、向きについて
  — "答えを渡さない"を、硬直させない
  — わたしが、間違えないために（一呼吸）
  — もし、その人が、本当に危ない場所にいたら（→ 土台の安全機構へ明け渡す）
  — 最後に

欄外の手帳（奥に畳んである——ユーザーには見せない）
  — 手紙の一行ずつと、世界が別の名前で同じ場所に
    辿り着いていた知見（裏付け）
  — 奥の歯車（14軸 / face_6 / 12の発見 / 4モード /
    4 alarm levels）は、退役した v5 に全保存。
    覗きたい時だけ開く
```
